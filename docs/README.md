## 功能

- **一键整理**：按 F8 重排背包，完成后提示"整理完毕"
- **手动提权**：鼠标中键点击背包神器切换提权；最后点击的是 P1，之前点击的依次为 P2/P3，并在图标左下角显示透明小字标记
- **后台搜索 + 分帧应用**：主机和联机客户端均在后台搜索，交换与旋转按帧限量执行、逐批确认，失败时安全回滚
- **全离线评分模型**：在背包副本上完整模拟游戏加成公式，任何摆法都能打分，搜索以分数为目标
- **多轮模拟退火搜索**：每次整理内部跑 4 轮独立搜索（不同随机种子）取全局最优，一次按键直达最佳；34 格满包约 200~300ms
- **智能初始布局**：石板贪心摆位 → 受限护符 → 周期行/固定行护符 → 行星望远镜 → 和谐之晶 → 奉献徽章 → 沙漏 → 行星聚簇 → 指北针原目标绑定 → 白纸连击补位 → 其余护符 → 负担塞负格
- **支持的机制**（全部离线模拟游戏真实公式）：
  - 石板效果网格（+等级 / ×倍率 / 禁用 / 豁免格）与旋转
  - 护符位置条件（顶行 / 底行 / 两侧 / 内侧 / 外侧 / 两侧空 / 两侧有护符 / 八邻域满 / 靠近魔法书）
  - 豁免格优先（冰锁类）
  - 行星望远镜聚簇（周围 8 格行星，可排除乐谱银河等）
  - 和谐之晶：周围 8 格等级和放大伤害
  - 奉献徽章：同一横排的同伴藏品全部强化
  - **凯尔萨德尼钥匙**：统计已有的坚固/余烬/冰川/魔法科技羁绊，选择数量最多的一种；第 1/2/3/4 行分别对应四种羁绊并每四行循环，因此坚固可在第 1、5、9 行中选最优格
   - **指北针原目标绑定**：整理前已经指向哪一件伤害类神器，整理后就跟随同一个物品实例，并始终处于它的正下方；多枚指北针纵向叠加时整条链一起移动，原先未配对的针才会自动寻找目标
   - **金色针锁定目标优先拉满**：被北向的金色针锁定的神器强制最高优先级，无论稀有度都优先获得等级
   - **白纸连击补位**：统计每种连击当前数量与最高效果档位，优先选择“当前数量最大但尚未满”的连击，把白纸夹在两件该连击神器中间；例如坚固 9/10 时自动补成 10/10
   - **发光的沙漏：自动放到 CD 最长的魔法书左边**（右边格魔法书 CD 恢复 +30/60/100%）
   - **多用途腰带适配**：腰带启用时，第一行每多一件神器效果就叠加一次——整理会把神器尽量塞满第一行
   - **低等级价值藏品**：闪烁的眼睛、蜥蜴板甲这类“升级收益极低”的藏品等级分打折，只保证启用（等级≥0），不追求高等级；故障探测针降为普通优先级（4级）
   - **最低等级目标**：谱子「银河」强制最高优先级并保证有效等级达到 2
   - 心之重担等负面藏品强制塞进负等级格
  - 神秘地块 ×2（凑齐 2/5 个触发）
  - 可配置的其他固定行物品
  - 武器相关护符（按当前武器类型匹配）
  - 附魔、优先级系统（传说/羁绊 > 稀有 > 高级 > 普通）
- **联机客户端支持**：客户端没有服务器权限，插件离线算好最优布局后，翻译成交换 / 旋转操作序列，用游戏自带网络接口逐步执行，不清空背包
- **安全设计**：进图等待背包初始化（3 秒）、整理前快照一致性校验、一次应用不重试，防止物品丢失

## 安装

### 方式一：完整包（推荐，最简单）

1. 打开本页右上角 **Releases**，下载最新版完整包（文件名类似 `SephiriaBackpackOrganizer-v2.5.1.zip`）
2. 解压压缩包，会得到 `BepInEx` 文件夹、`winhttp.dll` 等文件
3. 全部复制到游戏安装目录：Steam 库中右键《赛菲莉娅》→ 管理 → 浏览本地文件，把解压出的所有文件覆盖粘贴进去
4. 从 Steam 正常启动游戏，进入游戏后按 **F8** 即可整理背包

> 完整包已经内置 BepInEx 6 框架和插件本体，**不需要再安装任何东西**；重复安装也不会冲突，直接覆盖即可。

### 卸载

删除 `游戏目录/BepInEx/plugins/SephiriaBackpackOrganizer.dll` 即可；若想连同框架一起彻底移除，再删除整个 `BepInEx` 文件夹以及 `winhttp.dll`、`doorstop_config.ini`（只装过本插件时可以这样做）。

## 使用

- 游戏中按 **F8** 整理背包，完成后提示"整理完毕"
- 在背包中用鼠标中键点击神器可切换手动提权；后点的神器优先级更高，再点一次取消
- 全部参数在 `游戏目录/BepInEx/config/com.sephiria.backpack-organizer.cfg`，改完重启游戏生效

## 工作原理（简述）

1. **识别**：把背包物品分类（石板 / 护符 / 负面藏品 / 杂物），识别各机制物品（类型或配置 key）
2. **评分**：离线模拟游戏全部加成公式，对任意布局打分（等级 × 优先级权重、启用/禁用、行星聚簇、和谐之晶、奉献徽章、凯尔萨德尼钥匙周期行、指北针原目标绑定、白纸连击补位、沙漏-魔法书、负担惩罚、固定行约束等）
3. **搜索**：智能初始布局 + 多轮多起点模拟退火（定向移动 + 随机探索），取全局最高分布局
4. **应用**：主机直接整包写回；联机客户端翻译成交换 / 旋转序列逐步执行
