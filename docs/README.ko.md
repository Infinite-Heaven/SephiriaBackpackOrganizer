*Sephiria*(Steam AppID 2436940)용 BepInEx 플러그인입니다. **F8**을 누르면 가방을 자동으로 정리해 석판 커버리지, 부적 위치 조건, 행성 클러스터, 하모니 크리스탈, 헌신 배지, 켈사르단니 열쇠 순환 행, 나침반 원래 대상 고정, 백지 콤보 채우기, 빛나는 모래시계 등 모든 시너지 메커니즘을 한 번에 발동시킵니다.

- 버전: v2.5.1
- 버그 수정: 수동 우선순위 아이템이 원본 게임 점수 하락 때문에 잘못 롤백되지 않습니다. P1/P2/P3의 레벨당 보너스는 6000/5800/5600이며 음수 레벨에는 같은 값의 페널티가 적용됩니다
- 런타임: BepInEx 6 (Unity Mono) / Unity 6000.3.21f1 / Mirror 멀티플레이
- 솔로, 호스트, 멀티플레이 클라이언트 모두 사용 가능

## 기능

- **원키 정리**: F8을 누르면 가방이 재배치되고 완료 토스트가 표시됩니다
- **수동 우선순위**: 가방 아이템을 마우스 가운데 버튼으로 눌러 우선순위를 전환합니다. 마지막 선택은 P1, 이전 선택은 P2/P3이며 아이콘 왼쪽 아래에 작은 투명 표식이 표시됩니다
- **백그라운드 검색 + 프레임 분할 적용**: 호스트와 클라이언트 모두 백그라운드에서 검색하고 교환/회전을 프레임별로 검증하며 적용하고, 실패 시 안전하게 되돌립니다
- **완전 오프라인 점수 모델**: 가방의 복사본에서 게임의 실제 보너스 공식을 시뮬레이션합니다 — 어떤 배치든 점수가 매겨지고 검색은 그 점수를 최적화합니다
- **다중 라운드 시뮬레이티드 어닐링**: 누를 때마다 4번의 독립 검색(다른 랜덤 시드)을 실행해 전역 최적을 선택합니다. 34칸 가방 기준 약 200~300ms
- **스마트 초기 배치**: 석판 → 제한 부적 → 순환/고정 행 부적 → 행성 망원경 → 하모니 크리스탈 → 헌신 배지 → 모래시계 → 행성 클러스터링 → 나침반 원래 대상 고정 → 백지 콤보 채우기 → 나머지 부적 → 부담을 최악의 칸으로
- **지원 메커니즘** (모두 게임의 실제 공식을 미러링):
  - 석판 효과 그리드 (+레벨 / ×배수 / 비활성화 / 조건 무시 칸) 및 회전
  - 부적 위치 조건 (상단 / 하단 / 양측 / 내부 / 외곽 / 양쪽 비어 있음 / 양쪽 부적 / 8방향 가득 / 마법책 근처)
  - 조건 무시 칸 우선 (얼음 자물쇠류)
  - 행성 망원경 클러스터 (주변 8칸; 은하 악보 등 제외 가능)
  - 하모니 크리스탈: 주변 8칸의 레벨 합에 비례해 데미지 증가
  - 헌신 배지: 같은 행의 동료 아이템 전체 강화
  - **켈사르단니 열쇠**: 기존 STURDY/EMBER/GLACIER/MAGITECH 시너지를 세어 가장 많은 것을 선택합니다. 행 1/2/3/4가 네 가지 유형에 대응하고 4행마다 반복되므로 STURDY는 행 1/5/9 중 최적 칸을 선택합니다
  - **나침반 원래 대상 고정**: 정리 전에 이미 데미지 아이템을 가리키던 나침반은 정리 후에도 같은 인스턴스를 따라가며 그 바로 아래에 유지됩니다. 세로로 쌓인 나침반은 하나의 세로 체인으로 함께 이동합니다. 짝이 없는 나침반만 자동으로 대상을 찾습니다
  - **황금 바늘 대상 우선 만렙**: 북쪽을 향한 황금 바늘이 고정한 아이템은 희귀도와 무관하게 최고 우선순위가 되어 레벨을 먼저 받습니다
  - **백지 콤보 채우기**: 각 콤보의 현재 수와 최대 단계를 세어 아직 가득 차지 않은 가장 큰 콤보를 우선 선택하고, 그 콤보 아이템 두 개 사이에 백지를 배치합니다 — 예: STURDY 9/10을 10/10으로 자동 완성
  - **빛나는 모래시계: 재사용 대기시간이 가장 긴 마법책의 왼쪽에 자동 배치** (오른쪽 칸의 마법책 재사용 대기 회복 +30/60/100%)
  - **다목적 벨트 지원**: 벨트가 활성화되면 맨 윗줄의 아이템 하나당 효과가 한 번씩 중첩됩니다 — 정리기가 맨 윗줄에 최대한 많은 아이템을 채웁니다
  - **레벨 가치가 낮은 부적**: 섀도우 아이와 도마뱀 판금 갑옷은 레벨 업 이득이 거의 없어 레벨 점수가 할인되며, 활성화(레벨 ≥ 0)만 보장하고 높은 레벨을 추구하지 않습니다. 고장 탐지 바늘은 일반 우선순위(4등급)로 내려갑니다
  - **최소 레벨 목표**: 은하 악보는 최고 우선순위가 되어 유효 레벨 2를 우선 보장받습니다
  - 마음의 부담 같은 부정 아이템은 최악(음수 레벨)의 칸으로 강제 배치
  - 신비 ×2 칸 (신비 아이템 2/5개일 때 해금)
  - 설정 가능한 고정 행 아이템
  - 무기 관련 부적 (현재 무기 유형이 일치할 때만 활성화)
  - 강화 레벨과 우선순위 시스템 (전설/연대 > 희귀 > 고급 > 일반)
- **멀티플레이 클라이언트 지원**: 서버 권한 없이 로컬에서 최적 배치를 계산한 뒤 게임의 네트워크 연산(Swap / DoClickAction)으로 단계별 적용 — 가방을 비우지 않습니다
- **안전장치**: 세션 진입 후 가방 초기화를 3초 기다리고, 정리 전 스냅샷을 검증하며, 결과를 한 번만 적용하고 재시도하지 않아 아이템 손실을 방지합니다

## 설치

### 방법 1: 전체 패키지 (권장, 가장 간단)

1. 이 페이지 오른쪽 위 **Releases**에서 최신 전체 패키지를 다운로드합니다 (파일명 예: `SephiriaBackpackOrganizer-v2.5.1.zip`)
2. 압축을 풀면 `BepInEx` 폴더, `winhttp.dll` 등이 나옵니다
3. 모든 파일을 게임 폴더에 복사합니다: Steam에서 *Sephiria* 우클릭 → 관리 → 로컬 파일 보기, 압축을 푼 모든 파일을 덮어쓰기 붙여넣기
4. Steam에서 게임을 실행한 후 게임 내에서 **F8**을 눌러 가방을 정리합니다

> 전체 패키지에는 BepInEx 6 프레임워크와 플러그인 자체가 포함되어 있습니다 — 추가로 설치할 것이 없습니다. 재설치해도 안전하며 그냥 덮어쓰면 됩니다.

### 제거

`게임 폴더/BepInEx/plugins/SephiriaBackpackOrganizer.dll`을 삭제하세요. 프레임워크까지 완전히 제거하려면 `BepInEx` 폴더 전체와 `winhttp.dll`, `doorstop_config.ini`도 삭제하세요 (다른 BepInEx 플러그인을 설치하지 않은 경우에만).

## 사용법

- 게임 내에서 **F8**을 눌러 가방을 정리하면 완료 토스트가 표시됩니다
- 가방 아이템을 마우스 가운데 버튼으로 눌러 수동 우선순위를 전환합니다. 나중에 선택한 아이템의 우선순위가 더 높고, 다시 누르면 취소됩니다
- 모든 설정은 `게임 폴더/BepInEx/config/com.sephiria.backpack-organizer.cfg`에 있으며, 편집 후 게임을 재시작하세요

## 작동 원리 (요약)

1. **인식**: 가방 아이템을 분류 (석판 / 부적 / 부담 / 기타)하고 각 메커니즘 아이템을 식별 (유형 또는 설정 키 기준)
2. **점수**: 게임의 모든 보너스 공식을 오프라인으로 시뮬레이션하고 어떤 배치든 점수를 매깁니다 (레벨 × 우선순위 가중치, 활성/비활성, 행성 클러스터, 하모니 크리스탈, 헌신 배지, 켈사르단니 열쇠 순환 행, 나침반 원래 대상 고정, 백지 콤보, 모래시계–마법책, 부담 패널티, 고정 행 제약 등)
3. **검색**: 스마트 초기 배치 + 다중 시작 다중 라운드 시뮬레이티드 어닐링 (지향 이동 + 무작위 탐색), 전역 최적 배치 선택
4. **적용**: 호스트는 전체 배치를 한 번에 기록; 멀티플레이 클라이언트는 교환/회전 시퀀스로 변환해 단계별 실행
